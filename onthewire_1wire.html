Understanding 1-Wire Protocol

Dallas Semiconductor's 1-Wire protocol transmits data over a single wire using precise pulse timing. The bus idles HIGH, and the master initiates communication with a reset pulse. Devices respond with a presence pulse, followed by data transmission where bit values are determined by how long the line stays LOW.

Decoding the Signal

The decoder measures each LOW pulse duration by tracking falling edges (1→0) and rising edges (0→1). Pulses under 30μs are classified as binary 1, while longer pulses are binary 0. Since 1-Wire transmits LSB-first, each 8-bit group is reversed before ASCII conversion.

1-Wire Protocol Specifications

Signal Phase Duration Description
Reset Pulse 480μs min Master pulls line LOW to initiate
Presence Pulse 60-240μs Slave responds after reset
Write 1 1-15μs LOW Short pulse = logic HIGH
Write 0 60-120μs LOW Long pulse = logic LOW

Complete Decoder Script

decode.py
#!/usr/bin/env python3 """1-Wire Protocol Decoder for SANS Holiday Hack 2025""" import sys start_time = 0 in_data = False bit_string = "" BIT_THRESHOLD = 30 # μs - differentiates 1 vs 0 for line in sys.stdin: try: if '"presence"' in line: in_data = True continue if not in_data: continue parts = line.strip().split(',') timestamp = int(parts[0]) level = int(parts[1]) if level == 0: start_time = timestamp # Falling edge elif level == 1 and start_time > 0: duration = timestamp - start_time bit = "1" if duration < BIT_THRESHOLD else "0" bit_string += bit start_time = 0 except: continue # Decode LSB-first bytes to ASCII for i in range(0, len(bit_string), 8): byte = bit_string[i:i+8][::-1] # Reverse for MSB print(chr(int(byte, 2)), end='')
