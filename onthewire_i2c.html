Understanding I²C Protocol

I²C (Inter-Integrated Circuit) is a multi-master, multi-slave bus using just two lines: SDA (data) and SCL (clock). Unlike SPI's dedicated chip-select lines, I²C uses 7-bit addresses to identify devices. Each transaction begins with a START condition and includes address, read/write bit, acknowledgments, and data bytes.

I²C Protocol Details

Element Description This Challenge
START SDA falls while SCL high Marks transaction begin
Address 7-bit device identifier 0x3C = temperature sensor
R/W Bit 0=Write, 1=Read All transactions are WRITE

Data 8-bit payload bytes 5 bytes, XOR encrypted
STOP SDA rises while SCL high Transaction complete

Complete Parser Script

i2c_decoder.py
import json TARGET_ADDR = 0x3C XOR_KEY = "bananza" def parse_i2c(sda_file, scl_file): # Parse SDA events - contains START markers and data bits sda_events = [json.loads(l.split('\t')[0]) for l in open(sda_file)] scl_events = [json.loads(l.split('\t')[0]) for l in open(scl_file)] # Group by START markers to separate transactions transactions = [] current = {'sda': [], 'scl': []} for evt in sda_events: if evt.get('marker') == 'start': if current['sda']: transactions.append(current) current = {'sda': [], 'start_t': evt['t']} current['sda'].append(evt) # Match SCL sample points to extract bits for trans in transactions: sda_map = {(e['byteIndex'], e['bitIndex']): e['v'] for e in trans['sda'] if 'byteIndex' in e} # Extract address and filter for target addr_byte = int(''.join(str(sda_map[(0,i)]) for i in range(8)), 2) address = addr_byte >> 1 if address == TARGET_ADDR: # Extract and decrypt data bytes data = [int(''.join(str(sda_map[(b,i)]) for i in range(8)), 2) for b in range(1, 6)] decrypted = ''.join( chr(d ^ ord(XOR_KEY[i % len(XOR_KEY)])) for i, d in enumerate(data)) print(f"Temperature: {decrypted}°C")
