Understanding SPI Protocol

SPI (Serial Peripheral Interface) is a synchronous, full-duplex communication protocol using four signal lines. Unlike 1-Wire's timing-based encoding, SPI uses a dedicated clock line — data is sampled at each clock pulse, making extraction straightforward once you identify the sample points.

XOR Decryption Visualized

Data Extraction Pipeline

# Step 1: Extract sample timestamps from SCK egrep -o '".*"' spi_sck.burp | sort -u | \ sed 's/:/,/g' | sort -k4 -n -t, | \ grep '"v",1,"marker","sample"' | \ cut -d, -f4 | tr -d '"' > sck_sample_points.txt # Step 2: Process MOSI data through decoder egrep -o '".*"' spi_mosi.burp | sort -u | \ sed 's/:/,/g' | sort -k4 -n -t, | \ python3 decode_and_xor.py

Complete Decoder Script

decode_and_xor.py
#!/usr/bin/env python3 """SPI XOR Decoder for SANS Holiday Hack 2025""" import sys XOR_KEY = "icy" KEY_BYTES = [ord(c) for c in XOR_KEY] def load_sample_points(filename): with open(filename) as f: return sorted([int(t.strip()) for t in f]) def load_mosi_data(): mosi = {} for line in sys.stdin: fields = line.strip().split(',') timestamp = int(fields[3].strip('"')) value = int(fields[5].strip('"')) mosi[timestamp] = value return mosi # Sample MOSI at each clock rising edge sample_times = load_sample_points("sck_sample_points.txt") mosi_data = load_mosi_data() mosi_ts = sorted(mosi_data.keys()) bit_string = "" for t in sample_times: for mosi_t in reversed(mosi_ts): if mosi_t <= t: bit_string += str(mosi_data[mosi_t]) break # Convert to bytes and XOR decrypt for i in range(0, len(bit_string), 8): byte = int(bit_string[i:i+8], 2) key = KEY_BYTES[i//8 % len(KEY_BYTES)] print(chr(byte ^ key), end='')
