1-Wire Protocol

Dallas Semiconductor's Single-Wire Communication

📋 The Challenge

The 1-Wire protocol encodes data through precise pulse timing on a single wire. The bus idles HIGH, with bit values determined by how long the line stays LOW after each falling edge. Short pulses (~15μs) represent binary 1s, while longer pulses (~60μs) represent 0s.

2 Find "presence" marker
3 Measure pulse durations
4 Decode LSB-first bytes

SPI Protocol

Serial Peripheral Interface with XOR Encryption

📋 The Challenge

SPI uses a dedicated clock line (SCK) to synchronize data transfer. The MOSI line carries encrypted data that must be sampled at each rising clock edge. Using the XOR key "icy" from Part 1, we decrypt the captured payload to reveal the next clue.

I²C Protocol

Multi-Device Bus Analysis & Temperature Extraction

📋 The Challenge

I²C is a multi-master, multi-slave bus with 4 devices at different addresses. We must filter transactions for address 0x3C (the temperature sensor), extract the encrypted data bytes, and apply XOR decryption with key "bananza" to reveal the final temperature reading.

XOR Decryption Function

python
def xor_decrypt(ciphertext_bytes, key): """Repeating-key XOR decryption""" key_bytes = [ord(c) for c in key] plaintext = "" for i, byte in enumerate(ciphertext_bytes): plaintext += chr(byte ^ key_bytes[i % len(key_bytes)]) return plaintext # SPI: xor_decrypt(data, "icy") # I2C: xor_decrypt(data, "bananza")
